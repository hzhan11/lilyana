Dataset: Breast Ultrasound Images Dataset (BUSI), curated subset
Source: https://zenodo.org/records/21128640
Zenodo DOI: 10.5281/zenodo.21128640
License recorded on Zenodo: CC BY 4.0

Contents:
- BUSI/images: 629 ultrasound images (420 benign, 209 malignant)
- BUSI/labels: 629 corresponding segmentation masks
- BUSI.zip: downloaded source archive

The archived subset does not include normal-class images. Image dimensions
vary; the verified width range is 190-1048 pixels and height range is
324-719 pixels.

Original dataset reference:
Al-Dhabyani W, Gomaa M, Khaled H, Fahmy A. Dataset of breast ultrasound
images. Data in Brief. 2020;28:104863.
https://doi.org/10.1016/j.dib.2019.104863
